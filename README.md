## GitHub Pages (Deprecated)
GitHub Pages should be disabled. If it is still enabled, it should only serve a redirect to the official site.

Disable GitHub Pages:
1. Repository **Settings**
2. **Pages** (left sidebar under “Code and automation”)
3. **Build and deployment** → **Source** → select **None**
4. Save
